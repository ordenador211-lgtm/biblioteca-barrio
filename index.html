📚 Biblioteca de Barrio - Aplicación de Gestión

Práctica de arquitectura de software orientada a componentes en Python.

⚙️ Estructura de Componentes

  • catalogo.py: Gestión de libros, ejemplares múltiples y reservas.
  • socios.py: Control de socios, estados y sanciones.
  • prestamos.py: Lógica de préstamos aplicando reglas de negocio y caducidad.
  • main.py: Interfaz de consola para la interacción con el usuario.

🔒 Reglas de Negocio Implementadas

  • Límite máximo de 2 libros prestados por socio.
  • Caducidad de préstamos a los 7 días.
  • Control de socios sancionados.
  • Gestión individual de ejemplares por cada título.

📈 Diagrama de Dependencias

    main.py ──> (prestamos.py, catalogo.py, socios.py)
    prestamos.py ──> (catalogo.py, socios.py) [mediante funciones públicas]
