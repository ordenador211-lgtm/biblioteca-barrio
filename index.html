📚 Biblioteca de Barrio

Práctica de arquitectura de software orientada a componentes en Python

⚙️ Estructura de Componentes

Componente Descripción de Responsabilidades
catalogo.py Gestión de libros, control de ejemplares múltiples y sistema de reservas.
socios.py Control de identidad de socios, estados y gestión de sanciones.
prestamos.py Lógica de negocio de préstamos, caducidad a 7 días y comunicación por funciones públicas.
main.py Interfaz de consola para la interacción fluida con el usuario.

🔒 Reglas de Negocio Implementadas

  • Límite estricto: Ningún socio puede tener más de 2 libros prestados simultáneamente.
  • Caducidad: Cada préstamo expira automáticamente a los 7 días.
  • Ejemplares múltiples: Cada título cuenta con varios ejemplares gestionados de forma individual.
  • Sanciones y Reservas: Los socios sancionados no pueden pedir libros, y se pueden reservar títulos agotados.

📈 Diagrama de Dependencias

main.py ├──> prestamos.py ──> (catalogo.py, socios.py) [vía funciones públicas] ├──> catalogo.py └──> socios.py
